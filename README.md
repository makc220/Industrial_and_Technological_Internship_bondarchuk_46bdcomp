# TechVision — корпоративний вебсайт

## 1. Опис проєкту

**TechVision** — інформаційний корпоративний вебсайт IT-компанії з адміністративною панеллю для керування вмістом.

Проєкт розроблено в межах навчального завдання «Розробка інформаційного корпоративного вебсайту з панеллю адміністратора».

Метою проєкту є створення вебзастосунку з клієнт-серверною архітектурою, базою даних для зберігання інформації та зручним інтерфейсом для відвідувачів і адміністратора.

## 2. Основні можливості

### Публічна частина
- Перегляд інформації про компанію.
- Ознайомлення з переліком послуг.
- Перегляд новин.
- Надсилання повідомлень через контактну форму.

### Адміністративна панель
- Авторизація адміністратора.
- Перегляд основної інформації про сайт.
- Додавання, редагування та видалення послуг.
- Додавання, редагування та видалення новин.
- Перегляд і видалення повідомлень відвідувачів.
- Завантаження та зміна аватара адміністратора.

## 3. Використані технології

| Технологія | Призначення |
|---|---|
| C# | Основна мова програмування |
| ASP.NET Core (.NET 10) | Серверна платформа |
| Blazor / Razor Components | Створення користувацького інтерфейсу |
| Entity Framework Core | Робота з базою даних |
| SQLite | Зберігання даних |
| HTML5, CSS3 | Структура та оформлення сторінок |
| Bootstrap | Адаптивний дизайн та компоненти інтерфейсу |
| Bootstrap Icons | Іконки інтерфейсу |

## 4. Структура проєкту

Основні каталоги та файли:

- `TechVision/Components/` — компоненти та сторінки вебзастосунку.
- `TechVision/Data/` — контекст бази даних.
- `TechVision/Models/` — моделі предметної області.
- `TechVision/Pages/` — сторінки авторизації.
- `TechVision/Services/` — допоміжні сервіси та ініціалізація адміністратора.
- `TechVision/wwwroot/` — статичні файли, стилі та ресурси.
- `TechVision/docs/` — документація проєкту.
- `TechVision/docs/USER_GUIDE.md` — посібник користувача.
- `TechVision/docs/screenshots/` — скриншоти вебсайту.
- `TechVision/Program.cs` — конфігурація та запуск вебзастосунку.
- `TechVision/techvision.db` — база даних SQLite.


## 5. Вимоги для запуску

Для запуску проєкту необхідно мати:

- Windows, Linux або macOS.
- Встановлений .NET 10 SDK.
- Середовище розробки Visual Studio, Visual Studio Code або інше середовище з підтримкою .NET.

## 6. Встановлення та запуск

1. Клонувати репозиторій:

   ```bash
   git clone <URL-репозиторію>
   ```

2. Перейти до каталогу проєкту:

   ```bash
   cd TechVision
   ```

3. Відновити залежності:

   ```bash
   dotnet restore
   ```

4. Запустити вебзастосунок:

   ```bash
   dotnet run
   ```

5. Відкрити адресу, зазначену в консолі після запуску застосунку.

База даних SQLite `techvision.db` входить до репозиторію та містить демонстраційні записи послуг, новин і повідомлень.

## 7. Доступ до адміністративної панелі

Для демонстраційного використання передбачено початковий обліковий запис адміністратора:

| Поле | Значення |
|---|---|
| Ім'я користувача | `admin` |
| Пароль | `ChangeMe123!` |

Сторінка входу: `/admin/login`.

Початковий обліковий запис створюється автоматично під час запуску, якщо в базі даних ще немає жодного адміністратора.
